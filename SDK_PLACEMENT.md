# Adobe After Effects SDK placement

The project was designed against the uploaded May 2023 Windows SDK.

For local/private development, extract:
`May2023_AfterEffectsSDK_Win.zip`

Then copy its `AfterEffectsSDK` folder to:

`extern/AfterEffectsSDK`

Required paths:
- `extern/AfterEffectsSDK/Examples/Headers`
- `extern/AfterEffectsSDK/Examples/Util`
- `extern/AfterEffectsSDK/Examples/Resources/PiPLtool.exe`

The repository does not include Adobe's SDK to avoid accidentally redistributing licensed third-party SDK material.
